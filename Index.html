Domoticz Nest

A private integration that shows my own Nest thermostat in my home automation system.

This app reads temperature, humidity, setpoint and heating status from a single Nest thermostat through the Google Smart Device Management API and passes those values to a Domoticz installation on my home network.

It is a personal project, used only by its owner. It is not offered to the public and does not accept sign-ups.
