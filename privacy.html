Privacy policy

Domoticz Nest · last updated 28 September 2026

Who uses this app

Domoticz Nest is a personal integration used only by its owner, for their own Google account and their own Nest thermostat.

What data is accessed

With the owner's consent, the app uses the Google Smart Device Management API to read thermostat data: ambient temperature, humidity, temperature setpoint, mode and heating status.

How the data is used and stored

The data is sent to a Domoticz installation on the owner's private home network, where it is displayed and logged. OAuth tokens are stored in a local configuration file on that same network. Nothing is stored on any other server.

Sharing

No data is sold, shared with third parties or used for advertising.

Revoking access

Access can be revoked at any time via Google Partner Connections or Google account permissions.
